Google Sans Flex

The typeface of Material 3 Expressive. Google Sans went open-source in 2025 as Google Sans Flex — a variable font now served on Google Fonts under the OFL license. This site itself uses it; here is everything we know, with values verified against the Google Fonts CSS API.

About

Google Sans descends from Product Sans (2015), the geometric typeface built from the redesigned Google l ogo to unify hundreds of product lockups. A decade of iteration on Pixel phones and Google apps culminated in Google Sans Flex, the open-source variable-font release — the letterforms behind Material 3 Expressive’s expressive typography. Google Design: Making Google Sans Flex

Get it: fonts.google.com/specimen/Google+Sans+Flex (OFL).

Axes — verified

Queried via the Google Fonts CSS API, Google Sans Flex is served in the normal style with two axes:

AxisRangeCSS property
wght (weight)100 – 900font-weight: 100 900
opsz (optical size)14 – 48font-optical-sizing: auto

Browsers apply opsz automatically from the rendered font-size: small text gets sturdier, tighter forms; large headings get more refined, open ones. No media queries needed.

/* the exact stylesheet this site loads */
https://fonts.googleapis.com/css2?family=Google+Sans+Flex:opsz,wght@14..48,100..900&display=swap

Some third-party builds (e.g. Fontsource mirrors) list additional axes. The Google Fonts API serves only wght + opsz — treat any other axis as unverified (TODO(spec)).

Weight combos & tips

With one variable file you get the whole 100–900 range. Our recommended combos for an M3 Expressive interface:

RoleWeightNotes
Body text400Never lighter than 400 for UI copy; below that only for oversized display.
Labels, chips, buttons, nav500M3’s label/t itle roles read best one step up from body.
Emphasized titles, active nav600The “Expressive” headline voice — strong without shouting.
Large display < 45px700Pair with tighter letter-spacing (-0.5%).
Hero display ≥ 45px800–900Let opsz refine the details; avoid 900 under 20px.
Thin 100–300 display onlyDecorative, large sizes only — fails contrast at text sizes.

Combo tips:

  • Limit yourself to 2–3 weights per view (e.g. 400 + 500 + 700). A variable font makes extra weights free bytes-wise, not free attention-wise.
  • Weight jumps signal hierarchy: use ≥ 2 steps (400 → 600), never 400 → 500, which reads as rendering noise.
  • Animate weight, not just color: a hovered card can go 500 → 600 — transition font-weight (interpolable on variable fonts) with our fast-effects spring for a genuinely expressive micro-interaction.
  • Emphasized type: M3 Expressive pairs large 600–700 display with 400 body for its signature contrast.

How to implement (CSS)

/* 1. Load (see self-hosting below for offline) */
<link rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Google+Sans+Flex:opsz,wght@14..48,100..900&display=swap">

/* 2. Use — optical sizing is on by default */
body {
  font-family: 'Google Sans Flex', Roboto, system-ui, sans-serif;
  font-weight: 400;
}

h1 { font-weight: 800; }          /* 100–900 all available */

/* 3. Animate weight (variable fonts interpolate) */
.tab { font-weight: 500; transition: font-weight var(--md-sys-motion-fast-effects-duration) var(--md-sys-motion-fast-effects); }
.tab[aria-current="page"] { font-weight: 700; }

/* 4. If you must pin opti
cal size */
.pin { font-variation-settings: 'opsz' 48; }

How to self-host

Three ways, best first:

1. npm — Fontsource (recommended)

npm install @fontsource-variable/google-sans-flex

// once, in your app entry point:
import '@fontsource-variable/google-sans-flex';   // wght axis, self-hosted

// font-family is 'Google Sans Flex Variable'
body { font-family: 'Google Sans Flex Variable', sans-serif; }
2. Manual woff2 + @font-face

Download the woff2 subsets from Google Fonts (the CSS API response lists the unicode-range subset URLs), then:

@font-face {
  font-family: 'Google Sans Flex';
  font-style: normal;
  font-weight: 100 900;             /* the full variable range */
  font-stretch: 100%;
  font-display: swap;
  src: url('/fonts/google-sans-flex.woff2') format('woff2');
  /* optional: unicode-range per subset, as Google serves it */
}

/* Preload the latin subset so swap rarely flashes */
<link rel="preload" href="/fonts/google-sans-flex-latin.woff2" as="font" type="font/woff2" crossorigin>

3. CDN (what this site does)

<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Google+Sans+Flex:opsz,wght@14..48,100..900&display=swap">

Performance tips

  • font-display: swap always — never block render on a font.
  • Keep the system-ui fallback in the stack so metrics stay close (Roboto is metrically near-identical).
  • Request only the axes you use: opsz,wght@14..48,100..900 beats *.
  • Preload only the latin subset; the API already unicode-range-splits everything else.
  • Size-adjust the fallback (@font-face { ... size-adjust: 100%; }) to kill layout shift (CLS).

With this library

The library tokens expose type sizes (--md-sys-type-*); point the family at Google Sans Flex:

:root {
  --md-sys-typescale-font: 'Google Sans Flex', Roboto, sans-serif;
}
/* emphasized pairs (wght 600–700 display variants) are a roadmap item */
