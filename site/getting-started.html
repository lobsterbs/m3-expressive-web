Getting started

Where to get it

Clone the repo (npm package publishing is on the roadmap):

git clone https://github.com/lobsterbs/m3-expressive-web.git
cd m3-expressive-web
npm install
npm run dev   # serves demo/index.html with all components

How to use it

Imp ort the library entry point (it injects the token stylesheet as a side effect), then use the custom elements:

import 'm3-expressive-web'; // or ./src/index.ts from the repo

<md-fil
led-button>Save</md-filled-button>
<md-fab-menu>…</md-fab-menu>

Or use the primitives directly:

import '@internal/state-layer.js';
import '@motion/springs.js'; // M3_SPRINGS constants + springToLinear()

How to configure it

Everything is driven by two token tiers. Override system tokens to retheme globally:

:root {
  --md-sys-primary: #006A6A;          /* retheme: your brand primary */
  --md-sys-motion-fast-spatial-duration: 233ms;
}
/* or scope per-component */
md-filled-button {
  --md-comp-filled-button-container-color: var(--md-sys-tertiary);
}

See Foundations for every token, and Components for per-component configuration.

The exact-values contract

Every value in this library is sourced from official Material 3 / MDC-Android token files. Anything unverifiable is marked // TODO(spec): <url> in the source — never invented. AI agents: see AGENTS.md and the skill on the agent-skills branch.
