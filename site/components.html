Actions

Common buttons ported

About. The primary M3 action component: five variants — filled, filled tonal, outlined, elevated, and text — with expressive state layers, ripple, and FAST-token spring motion on press.

When to use.

  • One primary action per view (filled)
  • Secondary/less emphasis: tonal, outlined, text
  • Destructive actions get confirmation via dialog

How to use.

<md-filled-button>Save</md-filled-button>
<md-tonal-button>Open</md-tonal-button>
<md-outlined-button>Cancel</md-outlined-button>
<md-elevated-button>Continue</md-elevated-button>
<md-text-button>Learn more</md-text-button>

How to configure.

--md-comp-filled-button-container-colorContainer fill
--md-comp-filled-button-label-text-colorLabel color
--md-comp-button-container-shapeCorner scale (full by default)
--md-sys-motion-fast-spatialPress/ripple spring

Where to get. Built into this library — see src/components.

Button group ported

About. A connected row of related buttons (segments) that can act as a toggle group or split actions. Expressive-new component; segments share the FAST spatial spring.

When to use.

  • Connected toggle selections (like segmented buttons)
  • Groups of related quick actions

How to use.

<md-button-group>
  <md-button-group-segment selected>Day</md-button-group-segment>
  <md-button-group-segment>Week</md-button-group-segment>
</md-button-group>

How to configure.

--md-comp-button-group-container-shapeOuter group shape (full)
--md-comp-button-group-segment-container-colorSegment fill (selected/unselected)

Where to get. Built into this library — see src/components.

FAB (floating action button) ported

About. A high-emphasis action button in three sizes (small/default/large) plus an extended variant. Expressive adds optional shape morphing (e.g. circle → soft-burst on press) and a loading state.

When to use.

  • The single most important action of a screen
  • Compose/creation actions

How to use.

<md-fab icon="add" label="Compose"></md-fab>
<md-fab extended label="Create">…</md-fab>

How to configure.

--md-comp-fab-container-colorFAB fill
--md-comp-fab-container-shapeShape (circle / morph target)
--md-comp-fab-large-container-height64px large / 56 default / 40 small

Where to get. Built into this library — see src/components.
