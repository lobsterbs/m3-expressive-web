Foundations

Every value here is canonical — sourced from the M3 spec and the MDC-Android token files that share the Expressive motion scheme.

Color

M3 uses color roles, not fixed colors: primary/secondary/tertiary/error plus neutral and neutral-variant, each with container pairs, and surface/on-surface roles. This port exposes them as --md-sys-* custom properties (light + dark via prefers-color-scheme). Components consume only roles, so overriding one variable rethemes everything. Spec: color roles.

Elevation

Icons

M3 pairs filled and outlined icon families. Use Material Symbols with the M3 defaults (24dp, optical sizing on). Spec: icons

Theming / configuration

Two tiers: --md-sys-* (system, role level) and --md-comp-* (component level, mapped from sys). Configure a component by overriding its comp tokens; retheme an app by overriding sys tokens. See Get started.
