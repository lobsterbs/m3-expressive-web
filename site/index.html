m3-expressive-web

Community port · exact spec values

Material 3 Expressive, finally on the web.

Google neve r shipped the Expressive update to Material Web Components. This port brings the new motion scheme, shape morphing, and expressive components to the web — with exact values from the canonical token sources, never invented ones.

Docs coverage — live wavy progress & loading indicator, built with this library's exact spring tokens.

The Expressive spring scheme — exact damping & stiffness, as CSS linear() curves.
